# Don't Touch the Red

A fast-paced 2D survival game where the goal is simple:

> **Don't touch the red.**

Move, react, and survive as long as possible while avoiding deadly red obstacles and hazards.

## 🎮 Play

## ✨ Features

* Fast-paced survival gameplay
* Simple and responsive controls
* Keyboard, mouse, and touch support
* Touch joystick support for mobile
* Score-based gameplay
* Increasing challenge
* Lightweight and browser-friendly
* Designed for desktop and mobile

## 🎮 Controls

### 🖥️ Keyboard

| Input | Action     |
| ----- | ---------- |
| **W** | Move Up    |
| **A** | Move Left  |
| **S** | Move Down  |
| **D** | Move Right |

### 🖱️ Mouse

**Click & Hold** — Move

### 📱 Touch

**Touch & Hold** — Move

**Touch Joystick** — Move

## 🚀 Running the Project

### Requirements

* Godot 4.x
* Git

### Clone the repository

```bash
git clone https://github.com/TUSHAR-SHAWw/Dont-Touch-The-Red.git
```

Open the project in Godot and run the main scene.

## 🌐 Web Export

The game is designed to run in modern web browsers using Godot's Web export.

For local testing, serve the exported files through a local web server instead of opening `index.html` directly.

Example:

```bash
python -m http.server 8000
```

Then open:

```text
http://localhost:8000
```
